# CLAUDE.md — «Фламінго»

Браузерний скролінг-шутер. Гравець керує українською ракетою «Фламінго» в лівій
третині екрана, світ скролиться вліво, а справа з наростаючою щільністю
з'являються російські перехоплювачі та абсурдні перешкоди. Очки = пройдена
відстань. Гра поділена на рівні (~30 с кожен), що позначаються дорожніми знаками
зі смішними назвами міст.

> Графіка — **placeholder**: усі об'єкти це кольорові прямокутники з підписами.
> Геймплей, фізика та структура — справжні й готові до заміни плейсхолдерів на
> спрайти без зміни логіки.

---

## Стек

- **Phaser 3** — рушій (рендеринг, сцени, Arcade-фізика, ввід).
- **TypeScript** (strict) — уся логіка типізована.
- **Vite** — dev-сервер і збірка.
- Збереження рекорду — `localStorage` (ключ `flamingo_best`).

### Команди

```bash
npm install      # встановити залежності
npm run dev      # dev-сервер на http://localhost:5173
npm run build    # типчек + продакшен-збірка у dist/
npm run preview  # переглянути зібраний білд
```

## Структура

```
src/
  main.ts                  # Phaser.Game config, реєстрація сцен, масштабування
  config/
    constants.ts           # GAME (розміри, швидкості, зони), COLORS, DEPTH
    levels.ts              # LEVELS[]: місто, тривалість, складність, типи перешкод
  entities/
    Player.ts              # «Фламінго»: рух, бонуси, невразливість, шлейф
    Obstacle.ts            # 5 типів перехоплювачів + їхні патерни руху
    Bonus.ts               # пальне (boost) і зірочка (невразливість)
    Parallax.ts            # 3-шаровий паралакс + наземні гег-об'єкти
    RoadSign.ts            # дорожній знак міста (звичайний / перекреслений)
  scenes/
    BootScene.ts           # меню, старт, показ рекорду
    GameScene.ts           # головний цикл: рівні, спавн, колізії, HUD, рахунок
    GameOverScene.ts       # екран поразки/перемоги, збереження рекорду
```

## Архітектура

### Цикл сцен

`Boot → Game → GameOver → (Game | Boot)`

`main.ts` створює `Phaser.Game` з масштабуванням `Scale.FIT` (гра тягнеться під
будь-який екран зі збереженням пропорцій 960×540) та Arcade-фізикою без гравітації.

### GameScene — серце гри

`GameScene` — єдиний оркестратор. Він **не** використовує вбудовані Phaser-групи
для спавну, а тримає прості масиви сутностей (`obstacles`, `bonuses`, `signs`) і
вручну викликає `update`/прибирання щокадру. Так логіка лишається явною й легко
читається.

**Структура рівня (машина станів `phase`):**

| Фаза    | Що відбувається                                                       |
|---------|----------------------------------------------------------------------|
| `intro` | В'їжджає знак з назвою міста, банер; спавну ворогів ще нема (~2.2 с)   |
| `play`  | ~30 с активного геймплею: спавн перешкод і бонусів за таймерами       |
| `outro` | В'їжджає **перекреслений** знак того ж міста, пауза, перехід далі     |

Після `outro` останнього рівня → перемога. Зіткнення в будь-який момент → поразка.

**Рахунок:** `distance` накопичує проскрольовані world-пікселі;
очки = `distance * scorePerPixel`. Активний boost множить швидкість (і рахунок).

**Колізії** рахуються вручну через `Geom.Intersects.RectangleToRectangle` по
тілах Arcade-фізики — простіше за колбеки `overlap` для невеликої кількості тіл і
дає повний контроль над тим, що відбувається при перетині.

### Сутності

Кожна сутність — самодостатній клас із власним `update(dt)`. Спільний контракт:

- `container: Phaser.GameObjects.Container` — візуальне представлення;
- `body: Arcade.Body` — фізичне тіло для колізій;
- `update(dt)` — рух (зазвичай дрейф вліво зі швидкістю світу);
- `isOffscreen()` / `done` — сигнал на прибирання.

**Obstacle** інкапсулює всі 5 патернів в одному класі (`OBSTACLE_CFG` +
`initMotion`). Додати новий тип = додати рядок у `ObstacleType`, запис у
`OBSTACLE_CFG`, гілку в `computeSpawn`/`initMotion`, і ввімкнути його в потрібних
рівнях у `levels.ts`.

**Parallax** малює небо/пагорби/будівлі/землю прямокутниками й сам прокручує
далекий і середній шари з різною швидкістю (ефект глибини). Наземні «геги»
(черги на заправці, хрущовки, барак тощо) спавняться періодично й їдуть із
землею.

## Як розширювати

| Хочу…                          | Де змінити                                                        |
|--------------------------------|------------------------------------------------------------------|
| Додати рівень/місто            | `config/levels.ts` → новий запис у `LEVELS`                       |
| Підкрутити складність          | `levels.ts`: `speedMul`, `spawnInterval`, набір `obstacles`      |
| Новий тип перешкоди            | `entities/Obstacle.ts` (тип + cfg + motion) і ввімкнути в рівнях |
| Новий бонус                    | `entities/Bonus.ts` + обробка в `GameScene.checkCollisions`      |
| Замінити плейсхолдери спрайтами| `preload()` у сцені + заміна `rectangle`/`text` на `sprite`      |
| Інша зона руху гравця          | `GAME.playerZone` у `config/constants.ts`                        |
| Глобальні швидкості/розміри    | `config/constants.ts`                                            |

### Заміна плейсхолдерів на справжню графіку

Логіка не зав'язана на вигляд. Щоб додати арт:

1. Додай `preload()` у `GameScene`/`BootScene` і завантаж атласи/спрайти.
2. У кожній сутності заміни створення `rectangle` + `text` на `this.scene.add.sprite(...)`.
3. Розміри фізичного тіла (`body.setSize`) лишай узгодженими зі спрайтом.
4. Більше нічого міняти не треба — спавн, рух і колізії працюватимуть як є.

## Контент (гумор)

- **Міста (рівні):** Муходоєво, Верхніє Зади, Сисєрть,
 Срамні Уди,  Розчленінград, Єлабуга.
- **Перехоплювачі:** кришка нафтосховища (крутиться, чорний дим), купол церкви
  (відривається й летить угору), пам'ятник Леніну (так само), башта танка
  (танк вибухає → башта стартує), ракета ППО (горизонтально справа наліво).
- **Наземні геги:** черги на заправці, депресивні постсовкові краєвиди.
- **Бонуси:** пальне (прискорення), зірочка (тимчасова невразливість).
