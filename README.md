# Фламінго 🦩

Браузерний скролінг-шутер. Веди українську ракету «Фламінго», ухиляйся від
російських перехоплювачів та проходь рівні-міста. Очки = пройдена відстань.

## Швидкий старт

```bash
npm install
npm run dev
```

Відкриється на `http://localhost:5173`.

## Керування

- **Стрілки** або **WASD** — рух
- **Миша / тач** — наведення
- **Space / Enter** — старт і рестарт
