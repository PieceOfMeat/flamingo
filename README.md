# Фламінго 🦩

Браузерний скролінг-шутер. Веди українську ракету «Фламінго», ухиляйся від
російських перехоплювачів (кришки нафтосховищ, куполи, Леніни, башти танків,
ракети ППО) та проходь рівні-міста. Очки = пройдена відстань.

## Швидкий старт

```bash
npm install
npm run dev
```

Відкриється на `http://localhost:5173`.

## Керування

- **Стрілки** або **WASD** — рух
- **Миша / тач** — наведення
- **Space / Enter** — старт і рестарт

## Збірка

```bash
npm run build     # → dist/ (статика, заливай на Netlify/Vercel/GitHub Pages)
npm run preview
```

Архітектура й гайд з розширення — у [CLAUDE.md](./CLAUDE.md).
